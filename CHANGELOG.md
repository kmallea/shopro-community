# ShoPro Community Updates

This is the public, user-focused record of noteworthy ShoPro changes. It highlights features, workflow improvements, important fixes, and known limitations that affect people using ShoPro for their productions.

It is intentionally curated rather than generated from every code change. Routine maintenance, internal refactors, infrastructure details, security-sensitive information, and fixes with no meaningful user impact are not published here.

## Unreleased

### Added

- Launched this public documentation and community-support repository.
- Added getting-started, live-show workflow, Test Mode, shared-role, OBS browser-source, and troubleshooting guides.
- Added structured forms for reporting bugs and requesting features.

### Improved

- Improved realtime collaboration and connection handling for shared shows.

### Fixed

- Test Mode highlights now remain separate from real-show highlights.
- Audience shared views now display the same aggregate connection summary as other roles.

## April 2026

### Added

- Added Test Mode for rehearsing show timing and transitions without changing the live show's timing history.
- Added role-specific shared views for Producers, Hosts, Guest Hosts, and Audience members.
- Added live participant presence so teams can see who is connected to a shared show.
- Added the ability to insert an unplanned topic while a show is running.
- Added segment reordering and a refreshed Edit Mode experience.
- Added reusable overlay theme management and improved theme controls.
- Added an install prompt so supported browsers can install ShoPro as an app.
- Added an X Spaces show template and education-focused segment option.

### Improved

- Improved the teleprompter with play/pause controls and clearer settings.
- Improved shared-show layouts, participant visibility, and editing behavior.
- Improved segment tags and colors so different parts of a rundown are easier to scan.
- Improved long URL display inside show content.
- Improved Spanish and Russian terminology across the interface.
- Improved caching and offline support for the installable web app.
- Improved timing displays for unusually long productions, including durations that span multiple days.
- Refreshed account navigation, footer links, branding, and several production-screen layouts.

### Fixed

- Corrected show-stop behavior for unusually long-running shows.
- Corrected smaller spacing and control issues in shared-show and theme-builder views.

## What stays private

Some changes should not appear in a public update log. ShoPro keeps details private when publishing them could expose security controls, infrastructure, customer information, abuse-prevention methods, or unresolved risks. Once a security-related fix is complete, these notes may describe the user-visible outcome without publishing technical details that could make ShoPro users less safe.

When reporting a public issue, do not include passwords, private share links, browser-source URLs, access tokens, or personal information. Follow the private reporting process in [SECURITY.md](SECURITY.md) for security concerns.
