## Ask for help

If the guides do not solve the problem, open a support question in the [issue tracker](https://github.com/kmallea/shopro-community/issues). Include the workflow, expected result, actual result, browser, operating system, and troubleshooting already attempted.

Before posting, remove credentials, role links, source URLs, private notes, email addresses, and production data.

## Bugs and feature requests

- Use the bug form for reproducible behavior that appears broken.
- Use the feature form for a new capability or workflow improvement.
- Search existing issues before opening a new one.

## Security issues

Never post a vulnerability publicly. Follow [SECURITY.md](SECURITY.md).
