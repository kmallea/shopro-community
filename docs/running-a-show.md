# Running a Show

Run Mode is the operational view for the real production. It shows the active segment, what is coming next, elapsed time, and the show's progress against its planned duration.

## Before starting

- Confirm you are operating the correct show.
- Make sure Test Mode has been exited.
- Confirm the show caller and backup operator.
- Verify collaborator links and connection status.
- Check OBS scenes and overlay visibility.
- Confirm remote guests can hear and be heard.

## During the production

Authorized operators can:

- Start and end the show
- Move to the previous or next segment
- Jump directly to another segment
- Add an unplanned live topic
- Mark important moments as highlights
- Show or hide supported graphics
- Follow notes and scripts

Use **Add Topic** when the production changes direction. This preserves the timing record better than repurposing an unrelated planned segment.

## Timing

ShoPro tracks overall elapsed time and segment timing. Planned segment durations are estimates, not automatic cutoffs. The show caller decides whether to shorten, skip, extend, or reorder content.

## Highlights

Add a highlight when something important happens. ShoPro captures its show-relative and segment-relative timing. Label highlights while the context is fresh so editors and publishers can find them later.

Test Mode highlights are temporary and isolated. They do not appear in the real show after a test is restarted, discarded, or exited.

## Ending and reviewing

End the show in ShoPro when the production actually finishes. Then use the post-show tools to review runtime, completed segments, timing variance, highlights, and chapter timestamps.
